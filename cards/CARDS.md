# Learning Cards

Four layers per card: **L0** a twelve-year-old can follow → **L1** the mechanism → **L2** how to use it → **limit** when it fails. Gap evidence follows each cluster.

## c22 上下文经济学（3 件）— 证据：HN 实战痛点：中部剪枝作废前缀缓存（所有人都想做、都因此放弃）；上下文太多太少都坏；相关信息散落各处

- **L82 缓存感知剪枝**：L0 删上下文不是免费的：删中间一段，后面全部要重算。它先算"删了省的钱 vs 重算赔的钱"，划算才删。L1 输入剪枝方案（位置/长度），估算缓存重算成本 vs token 节省，负收益 → 否决或改尾部删。L2 断言=①中部删除负收益被否、②尾部删除正收益放行。
- **L83 双阈值充足度**：L0 上下文不是越多越好，太少也傻——它给"信息够不够"设上下两条线，越线都报警。L1 量化当前上下文的关键信息覆盖度，双阈值判定：溢出 → 压缩，不足 → 补料。L2 断言=①超上阈报压缩、②低于下阈报补料。
- **L84 相关性邻接度**：L0 相关的信息要放在一起：答案的一半在开头、一半在结尾，中间隔一万字，模型容易顾头不顾尾。L1 量化相关信息在上下文中的分散度（关键块间距/总长），超阈建议**重组**而非压缩。L2 断言=①高分散建议重组、②集中不报。
